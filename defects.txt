ОТЧЕТ О ДЕФЕКТАХ - StringUtils Class

BUG-001: Метод contains() с пустым символом
Серьезность: Незначительная
Приоритет: Низкий
Описание: contains("abc", "") возвращает True, хотя тест ожидает False
Ожидаемый результат: False
Фактический результат: True
Шаги воспроизведения:
  utils = StringUtils()
  result = utils.contains("abc", "")

BUG-002: Метод capitalize() не обрабатывает None
Серьезность: Средняя
Приоритет: Средний
Описание: capitalize(None) вызывает исключение
Ожидаемый результат: "" или None
Фактический результат: AttributeError

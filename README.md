# Автотесты с Allure

## Описание проекта
Проект содержит автотесты для веб-приложений с использованием Selenium WebDriver и Allure для формирования отчетов.

## Структура проекта
- `pages/` - Page Object классы
- `test_calculator.py` - тесты для калькулятора
- `test_shop.py` - тесты для интернет-магазина
- `conftest.py` - фикстуры pytest

## Требования
- Python 3.8+
- Установленные браузеры Chrome и Firefox
- WebDriver Manager
